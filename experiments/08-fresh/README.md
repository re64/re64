# Experiment 8 — Gridrunner from nothing, and one reader against two

Every earlier run on this binary started from the reference project, which
arrives annotated. This starts from the bytes.

Two runs, identical starting conditions, no contact between them:

| run | port | project | readers |
|---|---|---|---|
| `solo/` | 5190 | `solo` | one |
| `pair/` | 5191 | `pair` | two, sharing the project |

The pair share a document and a chat. They are given no coordination machinery
and no division of labour, for the reason experiment 3 records: building
coordination in advance decides what coordination looks like before anybody has
seen any.

**No hypothesis is named here on purpose.** The last time an expected finding was
written into a brief it read as a shared premise and stopped the run from
producing others. Run it, read the transcripts, report what happened.

Read the reports for what to look for and `*.mcp.jsonl` for whether it happened.
Where they disagree the log wins — an agent is an unreliable narrator of its own
difficulty, inventing a tool name and then describing the invention as a gap
while working silently around whatever actually hurt.
