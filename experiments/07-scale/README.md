# Experiment 7 — collaboration at scale

Three readers, one shared document, Revenge of the Mutant Camels decrunched
(47KB, roughly ten times Gridrunner). The first program here big enough that two
readers are not in the same routine merely because there is nowhere else to be —
every collaboration run before this measured crowding.

`./setup.sh` stands it up from the disk image alone, through the ordinary tool
surface: upload the `.d64`, lay the packed file down, run the loader, capture the
decrunched image, declare the two targets. It seeds **no annotations at all**;
building the project is experiment 5's task and was done.

## What happened

648 tool calls. Unexplained bytes 40,359 → 13. They partitioned themselves by
territory with no machinery for it — one took the front end, one the high code,
one the data — which is the second run running to decline the coordination this
project deliberately has not built.

What they collided over was naming, and it was invisible: 123 names replaced
across 74 addresses, nobody told, and the losses were *disagreements* rather than
duplicates. That is what `add_label` becoming additive came out of.

## Against the reference

`assets/mutant-camels/reference/` is a human disassembly of the standalone
`.prg`, which is a **different build** from the disk's crunched one the readers
worked on — 92.9% byte-identical, with the divergence concentrated in graphics
and low memory (1997 of 2754 differing bytes below `$1000`) and only 33 bytes
across `$8000-$9FFF`. So it is an oracle for code and not for data.

On that basis, of its 507 code labels re64 decoded **469 (93%)** as code and has
a label at **485 (96%)**; of the 38 it did not decode, 33 are inside spans the
readers had declared data or text, which is the reference labelling its own data.
About five addresses are genuinely unaccounted for.

The depth is where the run falls short of a complete human disassembly: 153
hand-named addresses in the code ranges, and not one individual sprite named —
the readers identified the banks, rendered two to confirm what they were, and
moved on.
