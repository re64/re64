Keyboard shortcuts

Navigation

click operand
Jump to the address it references
click ◂ N refs
Jump to a referrer
Enter
Follow the operand on the current line
Backspace / Alt+←
Back, along the navigation stack
g
Jump to the address box
click a region
In the memory map, jump to where it starts

Labels

click label
Rename it in place
n
Name the current line, or rename its label
f
Mark as a function, or clear it. A function is an entry point, so this is how code nothing references gets decoded. Creates the label if there is none.
Enter
Commit the name
Esc
Cancel — clicking away also cancels
empty + Enter
Delete the label
Ctrl+Z
Undo the last edit — renames, deletions, type changes
Ctrl+Shift+Z
Redo — or the ↶ ↷ buttons, which name what they would revert
tags
[fn] declared, [code] a branch or jump target found by analysis, [entry] the start of a program or code region. All three are disassembly entry points; only [fn] is yours to set here — edit the project file for the rest.

View

▤ Map
Show or hide the memory map. Dragging the divider to the edge does the same thing, and the width you chose comes back.

Project

Ctrl+S
Save the project file and reanalyze
